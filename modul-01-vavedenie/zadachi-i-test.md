## Практическа задача: „Пекарна Бабината фурна“

„Бабината фурна“ е семейна пекарна в Стара Загора с два обекта. Има Facebook страница с 4 200 последователи и Instagram профил с 1 100. Сайт няма. Поръчки за торти и баници за събития приема по телефона. Собственичката, Надя, казва: „Публикувам всеки ден, хората харесват, но поръчките не растат.“

**Задача 1 (работа в група, 20 минути).** Подредете всичко, което пекарната прави и не прави, по етапите на RACE. Къде е най-голямата загуба?

| Етап | Какво прави сега | Какво липсва |
|---|---|---|
| Reach (достигане) | | |
| Act (взаимодействие) | | |
| Convert (реализация) | | |
| Engage (ангажиране) | | |

**Задача 2.** Предложете по една конкретна дейност за всеки вид медия (платена, собствена, спечелена), която Надя може да започне с бюджет до 150 евро на месец.

**Задача 3.** Напишете две изречения, с които бихте обяснили на Надя защо 4 200 последователи не са достатъчни.
